# Fallout 4 — Vanilla Plus RPG Modlist
### *Built on The Midnight Ride · SS2-Centric · Subversion Ending*

> A hand-curated, stability-first modlist for a deep RPG playthrough of Fallout 4.  
> **Not a Wabbajack list yet** — see [WABBAJACK.md](WABBAJACK.md) for the roadmap.

---

## Philosophy

This list doesn't try to be a graphics showcase or a survival overhaul. It asks one question:

> *What does Fallout 4 look like when it's treated as a serious RPG?*

The answer is: **Sim Settlements 2 as the city-building spine**, **faction overhauls that make every major group feel distinct and worth caring about**, **dialogue systems that actually let you roleplay**, and **an ending (Subversion) that rewards nuance over mass destruction**.

Everything here is additive. The vanilla game is still recognisable. The lore is intact. The stability is prioritised over feature count.

---

## Foundation

This list is built on top of **[The Midnight Ride](https://themidnightride.moddinglinked.com/)**, installed via Wabbajack. TMR provides the critical stability layer:

| Already Provided by TMR | Do NOT reinstall |
|---|---|
| Unofficial Fallout 4 Patch (UFO4P) | ✓ |
| Buffout 4 (crash logger) | ✓ |
| F4SE (Script Extender) | ✓ |
| Address Library | ✓ |
| High FPS Physics Fix | ✓ |
| Previsibines Repair Pack (PRP) | ✓ |

Everything in this list layers **on top** of TMR without duplicating or conflicting with it.

## Requirements

### Mandatory
- **Fallout 4** — Next-Gen / Anniversary Edition (latest version)
- **All Creation Club content** — the full AE bundle
- **[The Midnight Ride](https://themidnightride.moddinglinked.com/)** — installed and working before adding anything here
- **Mod Organizer 2** — required for correct load order management
- **Nexus Mods account** — most mods are Nexus-hosted

### Recommended Hardware
- CPU: Modern multi-core (Fallout 4 is CPU-bound, especially with SS2)
- RAM: 16GB minimum, 32GB recommended
- Storage: SSD strongly recommended — SS2 loads significantly faster on SSD
- GPU: Capable of running Fallout 4 at your target resolution — this list does not include ENB or heavy texture packs

## The Anchor Mod: Subversion

> **[Subversion — The Institute-Railroad Alliance Alternate Ending](https://www.nexusmods.com/fallout4/mods/50975)**

The entire faction overhaul layer of this list is built around enabling Subversion's ending: the Railroad infiltrates the Institute's leadership, reforms it from within, frees the Synths, ends the experiments, and reaches peace with the Brotherhood. Every faction mod was chosen with this ending in mind.

**Critical:** Always verify you are on the **latest version** of Subversion. Versions 1.0 and 1.1 had a hard incompatibility with UFO4P that was later patched. Do not install old versions.

## Mods to Avoid

These mods are **incompatible** with this list and must never be installed:

| Mod | Reason |
|---|---|
| Scrap Everything / Spring Cleaning | Destroys PRP precombines, breaks SS2 navmeshes |
| Mutant Menagerie — Life Finds a Way | Documented SS2 incompatibility (broken recruitment beacon) |
| Start Me Up Redux | Incompatible with SKK Fast Start; SS2 patch was WIP |
| Horizon | Incompatible with TMR and SS2 fundamentally |
| Any Bethesda.net-only mods | Can't be managed by MO2 |
